What each source can say

agent traces
computed from span metadata: that a call was made and how it ended, never what it carried
check
what checks/agent_traces.py reported for this run against the expectations the driver mode set
driver
the driver's own exit status, which folds in every check about content: outputs parsed, citations verified against the adapter log, and the filed timeline matching its receipt

A span shows that a tool was called and whether the call raised. It does not show what was filed, which passages were cited, or what the model wrote. What the surface accepted and which passages left it are in the adapter log; what the model wrote, citations included, is its output; the driver holds the one against the other.
