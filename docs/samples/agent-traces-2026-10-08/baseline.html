What each source can say

agent traces
computed from span metadata: that a call was made and how it ended, never what it carried
check
what checks/agent_traces.py reported for each run against the expectations its driver mode set
driver
the driver's exit status, which folds in every check about content

A span shows that a tool was called and whether the call raised. It does not show what was filed, which passages were cited, or what the model wrote. The driver holds the outputs against the adapter logs, and only its exit status carries that verdict here.
